# oh-my-skill

Personal agent skills. Each subdirectory is one skill with a `SKILL.md`.

## Skills

| Skill | What it does |
| --- | --- |
| [design-preview](design-preview/) | Reference UI options, charts, and labs served on a local port |
| [html-prototype](html-prototype/) | Clickable HTML product prototype from docs; confirms forks with design-preview; can save files to disk |

## Layout

```text
<skill-name>/
  SKILL.md
  scripts/      # optional
  assets/       # optional
  references/   # optional
```
